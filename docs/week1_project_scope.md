| **Project Name** | TalentRank (Explainable Machine Learning for Employee Promotion Prediction and Ranking) |
| **Domain** | Human Resource Management (HRM) / Machine Learning / Explainable AI |
| **Problem Statement** | Organisations need to review employee information when considering promotion decisions. However, investigating employee features associated with historical promotion outcomes and understanding prediction results can be challenging, especially when dealing with many employee records. Machine learning can help identify patterns in historical employee data and predict promotion outcomes. However, prediction results alone may not provide enough information for HR personnel and management to understand which employee features influence the predictions. Therefore, TalentRank aims to develop explainable machine learning models for employee promotion prediction and ranking, providing additional information to support HR and management reviews. |
| **Evidence of the Problem** | Evidence 1: Employee promotion prediction has been investigated using machine learning techniques and employee-related data. This shows that historical employee records can be used to investigate patterns associated with promotion outcomes.<br>Source / citation: Analysis and Prediction of Employee Promotions Using Machine Learning (2022). https://ieeexplore-ieee-org.ezproxy.utm.my/document/9943959<br><br>Evidence 2: Research on employee promotion prediction has also explored explainable AI methods to identify features that influence model predictions. This highlights the importance of understanding model outputs in addition to predicting promotion outcomes.<br>Source / citation: Explainable AI for Predictive Analytics on Employee Promotion (2023). https://ieeexplore-ieee-org.ezproxy.utm.my/document/10393141 |

| **Engineering Gap / Limitation** | What practical or technical limitation remains unresolved?<br>Gap / Limitation: Existing studies have demonstrated the use of machine learning for employee promotion prediction and the use of explainable AI to interpret model outputs. However, TalentRank will focus on developing an integrated workflow that combines employee promotion prediction, ranking based on predicted outcomes, and feature-level explanations in one system. This will help HR Talent Management Specialists and top management review prediction results and understand the features influencing them. The system will be developed as a decision-support tool rather than an automated promotion decision-maker. |
| **Initial Project Objectives** | O1: Investigate employee features associated with historical promotion outcomes.<br>O2: Develop machine learning models for promotion prediction and ranking.<br>O3 : Evaluate the predictive performance and interpretability of the developed machine learning models. |
| **Target Users** | HR Talent Management Specialists: To review employee prediction results and understand the features influencing model predictions. Top Management: To obtain additional information when reviewing employees for promotion consideration. Intended use: provide additional information for human review and discussion. |

| **Similar to EduAdvisor** | Both projects use AI techniques to support users in making more informed decisions. They process input data, generate useful outputs, and aim to make the results understandable to their target users. Both are designed as decision-support systems rather than replacing human judgement. |
| **Different from EduAdvisor** | EduAdvisor uses Retrieval-Augmented Generation (RAG) to answer student questions based on university documents. TalentRank uses structured employee data and machine learning models to predict historical promotion outcomes, rank employees based on predicted outcomes, and explain the features influencing the predictions. |
| **Responsible AI Risks (at least 2)** | Risk 1: Bias and Fairness - Historical promotion data may contain existing organisational biases. A machine learning model may learn and reproduce these patterns, potentially producing unfair predictions for certain employee groups.<br><br>Risk 2: Privacy and Data Protection - Employee information may contain sensitive or personal details. Data must be handled carefully, and confidential employee information must not be exposed or shared without proper permission.<br><br>Risk 3: Over-reliance on AI Predictions - HR personnel or management may treat model predictions and rankings as final promotion recommendations. The system must communicate its limitations clearly and ensure that final promotion decisions remain under human responsibility. |
| **Important Project Limitations** | - The dataset contains historical promotion outcomes and does not directly measure leadership potential.<br>- The dataset does not identify the specific higher position an employee was promoted into.<br>- Feature explanations show how features contribute to model predictions; they do not prove the actual reasons behind organisational promotion decisions.<br>- Employee rankings are based on model predictions and must not be treated as definitive promotion decisions.<br>- Dataset source, licence and usage rights must be checked before using or sharing the data. |
